# zvim

A small, Vim-like terminal text editor written in Zig. One static binary, no
runtime files, no plugins or Vimscript: just the editing.

    zig build                  # zig-out/bin/zvim
    zig build test             # unit tests
    ./sandbox/run.sh file.txt  # try it (see sandbox/README.md for the keys)

Requires Zig 0.17.

To install, copy one binary somewhere on your PATH; there's nothing else.
`zig build dist` builds small static binaries for Linux (x86_64, aarch64)
and macOS (x86_64, aarch64) into `zig-out/dist/`, with a `SHA256SUMS` file
(`sha256sum -c SHA256SUMS`), e.g.

    cp zig-out/dist/zvim-0.1.0-x86_64-linux ~/.bin/zvim

## Settings

zvim needs no configuration. Settings live only in a settings file,
`~/.config/zvim/zvimrc` (or `$XDG_CONFIG_HOME/zvim/zvimrc`), read at startup;
without it zvim uses the defaults. zvim never writes the file; make it
yourself if you want one. `zvim -c` (`--clean`) ignores it. `zvim --help`
lists every setting.

    " defaults shown
    set ignorecase smartcase   " /foo finds Foo; /Foo finds only Foo
    set autoindent             " new lines copy the indentation above
    set tabstop=4              " how wide a tab looks
    set noexpandtab            " Tab and > insert a tab...
    set shiftwidth=4           " ...or this many spaces, with expandtab
    set nonumber               " line numbers down the left...
    set norelativenumber       " ...or distances from the cursor's line
    set messagetime=1000       " ms a message shows before the status bar returns
    set noautoclose            " typed brackets and quotes come in pairs

A bad line is skipped and reported when zvim starts.

## Colours

Nothing is coloured until there are language files in
`~/.config/zvim/syntax/`, one per language: which files it's for, and which
words, comments, strings and numbers go in which group. None come with
zvim; write one for each language you want coloured:

    " ~/.config/zvim/syntax/mylang
    extensions ml
    keyword    if else while return
    type       int str
    span comment //
    span string " " escape=\ oneline
    numbers
    functions

The groups are comment, string, number, keyword, type, constant, function and
todo. Their colours are set in zvimrc, several groups at once if you like:

    color keyword type #e5c07b
    color comment grey

`zvim --help` describes every directive.

## Layout

The editor core does no I/O: keys go in, text and cursor come out. That keeps
nearly everything testable as "type these keys, expect this text".

| File | |
|---|---|
| `src/main.zig` | Event loop: reads keys, runs the editor, saves files, draws |
| `src/term.zig` | Raw mode, window size, resize signal, alternate screen |
| `src/keys.zig` | Terminal input bytes to keys (escape sequences, bracketed paste) |
| `src/ui.zig` | Draws the text, selection, status bar and command line |
| `src/Buffer.zig` | The text: a piece table with per-piece newline counts |
| `src/History.zig` | Undo/redo history of grouped edits |
| `src/text.zig` | UTF-8, display widths, stepping through a line's characters |
| `src/file.zig` | Loading, and atomic saving |
| `src/crash.zig` | Saves unsaved changes to a recovery file on a crash or hangup |
| `src/Editor.zig` | Editor state, key dispatch, edit primitives, undo, cursor and view |
| `src/editor/normal.zig` | Normal-mode keys: counts, operators, shortcuts, `.` |
| `src/editor/motions.zig` | Which key moves where; moving or handing a range to an operator |
| `src/editor/words.zig` | Word and `f`/`t` motions over plain lines |
| `src/editor/operators.zig` | `d y c > <` on ranges and lines, the register, `p`, `J`, `r` |
| `src/editor/visual.zig` | `v`, `V` and Ctrl-V selections, block insert and paste |
| `src/editor/insert.zig` | Insert mode, and text pasted into the terminal |
| `src/editor/autoclose.zig` | The `autoclose` setting: paired brackets and quotes |
| `src/editor/cmdline.zig` | The command line: `:` commands and `/` `?` search |
| `src/editor/settings.zig` | Settings and the settings file |
| `src/syntax.zig` | Language files and the highlighter |
| `src/editor/textobjects.zig` | `iw`, `i"`, `a(`, `ip` and the other text objects |
| `src/width_table.zig` | Generated by `tools/gen_width.py` from Unicode data |
